# FinanZen

FinanZen es una aplicación web desarrollada en Django bajo el patrón MVT. El proyecto representa una tienda virtual y permite cargar información en base de datos mediante formularios.

## Funcionalidades principales

- Carga de clientes
- Carga de productos
- Carga de compras
- Búsqueda de productos por categoría
- Herencia de plantillas HTML
- Panel administrador de Django

## Modelos

- Cliente
- Producto
- Compra

## Orden para probar la aplicación

1. Inicio
2. Clientes
3. Productos
4. Compras
5. Búsqueda de productos por categoría
6. Panel admin en `/admin`
